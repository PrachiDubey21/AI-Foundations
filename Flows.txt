AI → making computers perform intelligent tasks.
ML → computers learn patterns from data.
Deep Learning → ML using multi-layer neural networks.
Training → teaching the model using data.
Inference → using the trained model on new input.
Supervised Learning → learning with labeled answers.
Unsupervised Learning → finding patterns without labels.
Generative AI → generating new content.
LLM → a large model designed to work with language.
Responsible AI → building and using AI safely, fairly, and responsibly.

   Supervisedlearning --> Classification
